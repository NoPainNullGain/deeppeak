# Contributing to DeepPeak

## Local setup

1. Run `npm install`.
2. Run `npm run compile`.
3. Press `F5` in VS Code to launch the Extension Development Host.

Keep changes focused, avoid exposing API keys in logs or screenshots, and update the README when user-visible behavior changes.

## Pull requests

Describe the user-visible change, include the relevant validation steps, and keep unrelated formatting changes out of the pull request.
