# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting if it is enabled for the repository, or contact the repository maintainers privately.

Never include a DeepSeek API key in an issue, pull request, log, screenshot, or code change.

DeepPeak stores the API key with VS Code SecretStorage and sends it only to DeepSeek's documented balance endpoint.
